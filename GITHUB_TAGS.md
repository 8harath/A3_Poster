## How to Add Tags to Your GitHub Repository

### Step 1: Navigate to Repository Settings

1. Go to: `https://github.com/8harath/A3_Poster`
2. Look for the "About" section on the right sidebar
3. Click the ⚙️ (gear/settings icon)

### Step 2: Add Topics

1. In the "Topics" field, start typing a tag
2. Select from suggestions or press Enter to create custom tag
3. Add up to 20 topics
4. Click "Save changes"

### Step 3: Verify Visibility

1. Visit your repository's main page
2. Topics should appear below the description
3. Users can click topics to discover similar projects

## Tag Guidelines and Best Practices

### GitHub's Official Guidelines

1. **Lowercase only**: `pdf-generator` not `PDF-Generator`
2. **Hyphenate multi-word tags**: `html-to-pdf` not `htmltopdf`
3. **Be specific**: `a3-poster` over generic `poster`
4. **Avoid redundancy**: Don't use both `python3` and `python`
5. **Maximum 20 tags**: Prioritize most relevant

### Community Best Practices

1. **Research popular tags**: Check successful similar projects
2. **Think like a user**: What would you search for?
3. **Balance broad and narrow**: Mix generic (`education`) and specific (`navic`)
4. **Update regularly**: Refresh tags as project evolves
